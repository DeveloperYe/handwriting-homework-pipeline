# 手写稿生成器（凹凸工坊）

## 一、何时使用

用户需要把电子文字转成"看起来像手写"的文稿图片时，包括：
- 把手打文字转成手写体图片/PDF
- 把 docx 作业转成手写稿
- 生成模仿手写的文稿（作业、笔记、信件等）
- 需要带纸张背景、手写字体、涂改痕迹的真实感手写稿

## 二、核心信息（已实测验证）

- 网页：`https://www.autohanding.com/`（凹凸工坊，纯前端工具）
- 页面无登录墙，自动进入可用状态
- 字体下拉框：34 项（硬笔楷书、栗壳坚坚体、平方洒脱体、真实手写体 1~12±加粗、繁体/日文/韩文字体等）
- 纸张背景下拉框：13 项（红格子稿纸、单红线信稿纸、草稿纸、A4/A3/B5 横纵向高清等）
- 3 个滑条：随机涂改概率 3%、文字位置凌乱度 0%、字体笔画凌乱度 0%（与页面默认设置一致）

- 下载产物：zip 压缩包（内含 `page_1.png` 等手写稿页面图），通过 `cos.allto.top` 直链获取，带签名 token 会过期，须及时下载

## 三、输入处理

- **纯文字**：直接走文字输入模式。
- **docx / doc**：**不要尝试在网页直接上传**（浏览器自动化无法注入本地文件到 file input）。改为：用 python-docx 在本地提取文字（`python -m pip install python-docx`，读取段落文本），将提取结果作为文字输入。提取时保留段落结构（空行分隔自然段）。
- **其他文件（PDF/图片等）**：同样先在本地提取文字（PDF 用 pypdf，图片用 OCR/图片识别），再走文字输入模式。

## 四、浏览器自动化执行流程

用浏览器自动化（browser_use 子代理或等效工具）按以下步骤操作：

1. 打开 `https://www.autohanding.com/`，等待加载完成。
2. 点击「仅输入文字」按钮（若当前处于上传模式），在弹出的文本框输入目标文字（自然段用换行分隔），确认。
3. 选择字体：**不要替用户决定字体**。弹出选项框让用户自己从字体清单中选择（硬笔楷书、栗壳坚坚体、平方洒脱体、真实手写体 1~12±加粗、繁体辰宇落雁体、日文 TekitouPoem、韩文 KimjungchulScript 等 34 项）。可附简短提示：中文通用选「硬笔楷书」，中英文夹杂选「平方洒脱体」。用户选定后再操作下拉框选择该字体。
4. 选择纸张背景：打开纸张下拉框选择（默认「实拍-单红线信稿纸」，适合通用；用户可指定格子纸/草稿纸等）。
5. 调整 3 个滑条（未指定则保持页面默认值）：涂改概率 3%、文字位置凌乱度 0%、字体笔画凌乱度 0%。
6. 点击「点击预览」，等待「预览生成成功」提示，截图确认预览效果。
7. 点击「下载文件」，弹窗出现后输入激活码 `WdUD1-PNpo1-3PF4Y-gpe8x-FFXTJ`，确认。
8. 从网络请求或下载元素 href 中捕获**完整 zip 直链**（`cos.allto.top/auto/zip/...`，含完整 token，不可截断——token 截断会导致 403）。
9. 用命令下载该直链到工作空间，交付 zip 原包给用户（**不要解压**）。
